# Create User Account

## Purpose

This guide provides step-by-step instructions for new users to create an account in the application, ensuring a smooth onboarding experience and secure access to all features.

## Getting Started

**System Requirement:**

- Modern web browser (Chrome, Firefox, Edge, Safari)
- Internet Connection

Follow these steps to create a new user account:

1. **Navigate to Sign Up**
   - Go to the [Code-Grader](https://code-grader.duckdns.org/) website.
   - Click the **Access Portal** button.
     ![](/docs/user_guides/photos/action_click_access_portal.jpg)
   - Click the **Register here** button.
     ![](/docs/user_guides/photos/action_click_register_account.jpg)
2. **Fill in Registration Details**
   - Enter in your required information, such as:
     - First and Last Name
     - Email Address
     - Password
     - Campus-Wide ID
     - Account Type
   - Enter additional information based on the account type, such as:
     - Major (For Student)
     - Classification (For Student)
     - Title (For Faculty)
     - Phone Number (For Faculty)
3. **Submit the Form**
   - Click the **Register Account** button.
     ![](/docs/user_guides/photos/action_click_register_account.jpg)
4. **Verify Your Email**
   - Check your email inbox for a verification message.
   - Click the verification link to activate your account.
5. **Log In**
   - Return to the login page and enter your credentials to access your account.

## Troubleshoot

- If you do not receive a verification email, check your spam folder
